# Лабораторна робота №11 — Завантаження файлів

## Опис

Застосунок для завантаження зображень з перевіркою типу та розміру, попереднім переглядом і відображенням прогресу.

## Технології

- Nest.js
- React
- TypeScript
- Multer
- Axios

## Запуск backend

```bash
cd lab11/backend
npm install
npm run start:dev
```

## Запуск frontend

```bash
cd lab11/frontend
npm install
npm run dev
```

Frontend доступний за адресою `http://localhost:5173`.
